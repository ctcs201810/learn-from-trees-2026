# Learn from Trees 2026 — 一頁式活動網站（雙語）

## 放到 GitHub Pages
1. 建立 public repo（例如 learn-from-trees-2026）
2. 上傳 index.html 與 assets/ 整個資料夾到根目錄
3. Settings → Pages → Deploy from a branch → main /(root) → Save
4. 1–2 分鐘後取得網址：https://你的帳號.github.io/learn-from-trees-2026/
